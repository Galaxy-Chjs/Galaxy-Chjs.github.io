01 / ABOUT

研究与方向

目前主要研究多参考图像生成与模型路由，重点关注生成前的能力判断与路径选择。

近期工作围绕多参考条件下的生成质量与路由决策展开，尝试通过轻量的 capability probes， 在完整渲染之前识别模型与输入条件之间的能力匹配关系。

工程项目主要来自实际科研与开发需求，覆盖实验监控、模型存储、研究 Agent 与桌面工作流。 这些项目强调本地优先、可复现和明确的功能边界，并保留完整的测试与使用文档。

ROUTER
MULTIMODAL GENERATIONICLR SUBMISSION

MRG-Router: Pre-Rendering Routing via Capability Probes for Multi-Reference Image Generation

面向多参考图像生成的预渲染路由方法：利用 capability probes 在生成前评估候选路径对输入条件的处理能力，并据此完成路由选择。核心目标是在避免完整渲染开销的前提下，提高路由判断的针对性。
